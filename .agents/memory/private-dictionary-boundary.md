---
name: Private dictionary boundary
description: Product privacy rules for privately owned reference works imported for personal study.
---

Private dictionary sources are for personal, local use only. Never commit their EPUBs, publish their definitions or examples, sync their full content to mobile, or send their text to OpenRouter or another external model service.

**Why:** The product supports privately owned, potentially commercial reference works. The user explicitly wants the system to remain safe to pull and run locally without redistributing that source material.

**How to apply:** Keep original sources local and treat them as in-memory import inputs. Persist local study data only as needed on the user's database, generate new examples through a local-only Ollama endpoint, and send mobile clients only user-created or generated derivative cards.
