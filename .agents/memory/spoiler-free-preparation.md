---
name: Spoiler-free reading preparation
description: Product rules for using visual cards, thematic decks, semantic maps, and contextual examples without exposing book content.
---

The preparation experience must be spoiler-free: never show original excerpts, plot-specific facts, distinctive names, or details that reveal events from the book before reading.

**Why:** The app prepares readers for a book rather than summarizing it, and displaying source context can create copyright and spoiler problems.

**How to apply:** Generate original example sentences that preserve the target language technique, grammar, register, or semantic relationship without copying the book. Thematic decks and visual maps should use broad genre/language concepts, not plot-derived details. Treat examples in older persisted plans as unsafe unless they are explicitly marked as newly generated preparation material. Post-reading spaced review is intentionally out of scope for the first version.
